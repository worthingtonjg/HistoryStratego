# Focused manual checks for the new classroom flow

These are manual behavior checks, not claims that the new graphical flow has already passed.

1. Open the teacher portal. A wrong key should stay at teacher entry. Enter your chosen key: restore the current classroom, or show only Create classroom.
2. Open the student page separately. It should show code + Join, without teacher/recovery controls. Join with the four-character code. Confirm the teacher roster gains that student.
3. Refresh/reopen the teacher page and enter the same key. Confirm the same class/roster returns paused and existing NPC seats are not duplicated.
4. In a disposable class, choose New class and confirm. Old students should see Class ended. Enter the teacher key after restart; confirm a different code and empty roster. Old student tabs must not resume old games. Join next class should accept the new code.
5. If two teachers are available, create separate classes and confirm distinct active codes and separate rosters. Short codes are not promised to remain unique forever.

For an existing pre-update teacher session, open the teacher portal in that same tab first so its retained session recovery can be adopted. Do not reset a live class merely to test. Report the step and visible message if anything fails; no broad screenshot sweep is needed.
