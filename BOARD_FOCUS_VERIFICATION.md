# Board-focus mode

Board focus is opt-in after the matchup introduction, for players and teacher spectators. The classroom toolbar offers Board focus / Normal view; focus mode also has an in-canvas Normal view control. Refresh defaults to the normal layout. No browser fullscreen permission is required.

Focus uses a centered square viewport sized to the shorter Unity canvas dimension, with a matching square render target and camera framing that preserves the existing tabletop proportions. It hides the normal sidebar/fact panel while retaining turn/setup status, setup actions, pause/deadline notices, combat, friendly messages and read-only perspective switching. Return to normal view for the full instructions, profiles, facts and game log. Message choices use an opaque scrollable panel. Controls own pointer input so they cannot acknowledge combat or pick the underlying board.

A direct-touch test initially failed because touch gestures did not reach the existing IMGUI board mouse path. The WebGL bridge now translates a single canvas touch into that same path only while focus mode is active; it suppresses duplicate compatibility events and browser panning. Normal mode is unchanged.
